# C# Console Assignment

A modular C# console application containing a Number Guessing Game and a Student Grade Tracker, built following object-oriented principles.

## Features
- **Number Guessing Game**: Interactive game with bounded input validation and limited attempts (5 tries).
- **Student Grade Tracker**: Computes class averages, highest/lowest scores, and individual letter grades from an array of scores.
- **Robust Error Handling**: Utilizes `int.TryParse` and `double.TryParse` to gracefully recover from invalid user input.

## How to Run
1. Open the solution in **Visual Studio**.
2. Set `ZhuwaAssignment` as the Startup Project.
3. Press `Ctrl + F5` to build and run the application.
